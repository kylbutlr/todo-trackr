# Todo Trackr v1.0.0

Todo Trackr is an open-source personal task manager you can run on your own infrastructure. This release provides a standalone server/web workspace, a Chromium Quick Capture extension, and macOS source code.

## Included

- A Node.js 24/PostgreSQL server, compiled web workspace, and Docker Compose setup.
- Tasks, lists, priorities, due dates, stars, persistent attention alarms, and recovery/export.
- Explicit password protection or passwordless access for a deliberately private installation.
- Server selection in companion clients, without requiring App Switchr, Shortcut, Granola, Codex, or a maintainer-hosted account.
- MIT licensing, contribution guidance, privacy notes, and versioned installation instructions.

## Downloads

- `todo-trackr-server-1.0.0.tar.gz`: compiled server/web runtime and migrations. Requires Node.js 24 and PostgreSQL.
- `todo-trackr-extension-1.0.0.zip`: extract and load unpacked in Chromium. Update manually by replacing files and reloading the extension.
- `todo-trackr-source-1.0.0.tar.gz`: source, build inputs, and documentation, excluding historical private native update binaries.
- `SHA256SUMS`: checksums for these downloads.

Start with the [self-hosting guide](https://github.com/kylbutlr/todo-trackr/blob/v1.0.0/docs/self-hosting.md) and [extension instructions](https://github.com/kylbutlr/todo-trackr/blob/v1.0.0/apps/browser-extension/README.md).

## Scope and verification

One owner uses each installation. Multi-account hosting and general-purpose work-system adapters are outside v1. The existing hosted adapters retain legacy mappings and are disabled in standalone mode.

The Mac client is source-only in this release. No paid Apple Developer membership or notarized download is required. Source builds use manual updates.

Automated checks and the Docker/PostgreSQL rehearsal cover both password modes, concurrent edits, recovery/export, database dump/restore, restart persistence, and migration reruns. Native source compiles and passes its test suite. An installed Chromium-extension permission/capture check remains unverified; automated capture-flow tests do not establish that browser-level acceptance. See the [release plan](https://github.com/kylbutlr/todo-trackr/blob/v1.0.0/docs/self-hosted-release-plan.md) for the evidence boundary and development-only dependency notes.
